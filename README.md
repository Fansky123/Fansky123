## 代表项目

### 01 / [FanAPI](https://github.com/Fansky123/FanAPI)

**多渠道 AI API 聚合平台**

统一接入多种 AI 服务，将接口代理、路由、计费和管理后台整合在一个平台中。

- 支持 OpenAI、Claude、Gemini 协议与流式响应。
- 覆盖对话以及图片、视频、音频等生成任务。
- 提供多渠道路由、用户与 API Key 管理、计费和交易记录。

`Go` `Gin` `TypeScript` `PostgreSQL` `Redis` `NATS`

[查看代码与使用文档 →](https://github.com/Fansky123/FanAPI#readme)

### 02 / [QQ Codex Worker](https://github.com/Fansky123/qqbot)

**从 QQ 群命令到可审计的开发任务**

通过 OneBot 连接 QQ 群与 Codex，以明确的命令、权限和审批流程组织任务执行。

- 支持项目咨询、任务创建、状态查询与日志查看。
- 通过审批流程控制合并与部署操作。
- 使用 SQLite 保存任务状态与审计记录。

`Go` `OneBot 11` `SQLite` `Codex` `Automation`

> 当前面向本地工作站与 RC 环境验证；具体使用范围与隔离要求见项目文档。

[查看代码与使用文档 →](https://github.com/Fansky123/qqbot#readme)
